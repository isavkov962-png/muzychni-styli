# Музичні стилі — інструкції для продовження роботи

Навчальний застосунок для студентів (КМАМ ім. Р. Глієра). Мова — українська. Аналог застосунку «Музична форма» (`isavkov962-png/chopin-app`).

## Стан (05.11.2026)
- Етап: звіт про джерела і план — `plan.md` (чекає затвердження користувача).
- Частини: А — історичні стилі; Б — індивідуальні стилі; В — жанрово-національні; Г — баян/акордеон (відкладено до кінця).

## Порядок роботи
1. Для кожного розділу — звіт перевірки джерел і прикладів (**Opus**) → зупинитися, чекати затвердження.
2. Після затвердження — побудова розділу (**Sonnet**), перевірка в браузері (Playwright), push.
- Попереджати користувача заздалегідь, коли змінити модель. Одна сесія — один-два розділи.

## Правила (рішення користувача — див. `plan.md`, п. 0)
- Визначення — лише з джерел; не вигадувати цитат, сторінок, тактів.
- **Російських авторів-дослідників не використовувати.** Російські композитори — лише Рахманінов, Шостакович, Прокоф'єв, Стравінський (Рахманінов — через зв'язок із західною традицією, лише за джерелами).
- Пріоритет — українські автори; англомовні джерела дозволені. Переклад цитат — без позначки «переклад», але з автором, назвою, сторінкою.
- Приклади: джерело + нестрога звірка за нотами (такти). Можна скриншоти; посилання не лише на IMSLP. Твори під авторським правом — короткі фрагменти з підписом. Нот із пам'яті не відтворювати.
- Долі такту — словом.
